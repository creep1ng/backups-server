# Translation glossary — Spanish → English

This glossary records preferred translations for recurring technical terms used in the documentation. Use these translations consistently across the translated docs.

- Storage Box — Storage Box (preserve product name / proper noun)
- Borg / BorgBackup — BorgBackup (preserve product name; shortened to "Borg" where appropriate)
- append-only — append-only
- bind mount / bind mounts — bind mount / bind mounts
- Docker Compose — Docker Compose (preserve product name)
- volume / Docker volume — Docker volume
- repo / repository — repository
- snapshot — snapshot (archive created by Borg)
- archive (Borg) — archive
- stream / streaming — stream / streaming
- SSH — SSH (preserve acronym)
- SFTP — SFTP (preserve acronym)
- stdin — stdin (preserve technical term)
- systemd unit / timer — systemd unit / timer
- CLI — CLI (command-line interface)
- early return — early return (programming term)
- MVP — MVP (minimum viable product)

Notes:
- Proper nouns, product names and trademarks (e.g., "BorgBackup", "Docker Compose", "Hetzner Storage Box") are kept in original spelling and casing.
- When a Spanish phrase was ambiguous and the English meaning chosen could be one of several technical senses, the instance is flagged in the translated file with an inline HTML comment: <!-- TRANSLATION NOTE: ambiguous term — original: "..." -->
